# نشر الواجهة على GitHub Pages (PWA)

## 1) الخادم (Apps Script) — لا يتغيّر Code.gs
1. افتح مشروع Apps Script الحالي ← أضف ملفاً جديداً باسم **Api** والصق فيه محتوى `Api.gs`. (Code.gs وبقية الملفات كما هي.)
2. **Deploy ← Manage deployments ← ✏️ ← Version: New version**.
   - Execute as: **Me**
   - Who has access: **Anyone**  (ضروري ليعمل الطلب من GitHub؛ البيانات محميّة بالرمز السري + Token موقّع)
3. انسخ رابط الـWeb app (ينتهي بـ `/exec`) — نفس الرابط القديم.

## 2) الواجهة على GitHub
1. أنشئ مستودعاً جديداً (مثلاً `visits`) وارفع **محتويات مجلد web** (وليس المجلد نفسه): index.html, style.css, app.js, api.js, pwa.js, config.js, sw.js, manifest.webmanifest, مجلد icons.
2. عدّل `config.js` وضع رابط `/exec` مكان النص العربي.
3. **Settings ← Pages ← Source: Deploy from a branch ← main / (root)**.
4. بعد دقيقة يعمل التطبيق على `https://اسمك.github.io/visits/`.

## 3) التثبيت على الهاتف
- أندرويد/كروم: تظهر في شاشة الدخول «تثبيت التطبيق على الهاتف».
- آيفون/سفاري: مشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملاحظات
- كل مندوب يسجّل دخوله مرة واحدة على الجهاز (Token صالح 30 يوماً). تغيير الرمز السري أو تعطيل المندوب يُسقط جلسته تلقائياً.
- 5 محاولات خاطئة للرمز ← قفل 10 دقائق لذلك المندوب.
- اسم المندوب والمنطقة تُفحص في الخادم من الـToken، لا من المتصفح.
- التحديثات: يكفي رفع الملفات المعدّلة؛ التطبيق يجلب النسخة الجديدة تلقائياً عند وجود نت (وللعمل بلا نت يستعمل النسخة المخزنة). عند تغيير شكل الملفات رفّع `VERSION` في sw.js.
- النسخة القديمة (رابط Apps Script) تبقى تعمل بالتوازي.
